## Creative direction in one paragraph

Build a luxury high-fashion wedding editorial that feels like illustrated stationery brought to life: textured warm-ivory surfaces, intricate botanical engraving, refined architectural and landscape illustration, editorial typography, layered artwork, varied compositions, and purposeful motion. Keep the experience rich rather than sparse. Each section should have its own visual identity while remaining part of one coherent invitation.

## Status policy

- **HARD REQUIREMENT:** must be preserved (wedding facts, privacy/security, accessibility, approved RSVP model, explicit user-approved decisions).
- **CREATIVE BASELINE:** defines the project's identity, not a pixel-perfect template.
- **SUGGESTION:** one viable option; the agent may improve or replace it when the result remains on-concept.
- **PENDING:** content or assets have not yet been supplied.
- **NOT TESTED:** implementation or QA has not been evidenced.

The supplied illustrations are art-direction references, not a demand to copy every pixel. Use judgment to make the actual responsive site feel polished and alive.
