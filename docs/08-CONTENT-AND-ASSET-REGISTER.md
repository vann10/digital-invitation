## 4. Asset and implementation notes

- Prefer optimized SVG for suitable line art, transparent WebP/PNG for textured illustration, and responsive modern image formats for photographs.
- Keep texture subtle but visible at actual viewport scale.
- Test transparent edges against the actual background.
- The bird should retain consistent species, proportions, sketch language, and color across all positions.
- Avoid loading all large art only after the Opening CTA is pressed; preload or prioritize assets needed for the transition.
- Use `prefers-reduced-motion` behavior for the bird and the Opening-to-Hero sequence.
